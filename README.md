# Escala+ | Painel Operacional

Painel web desenvolvido para visualização e acompanhamento das escalas 12x8 de equipes operacionais.

## Sobre o projeto

O Escala+ Painel Operacional complementa o ecossistema Escala+, apresentando de forma visual a situação das turmas, ciclos de trabalho e folga e próximas movimentações.

O painel calcula automaticamente os ciclos a partir de datas de referência e atualiza as informações conforme a data atual.

## Funcionalidades

- Identificação automática das turmas embarcadas e de folga
- Cálculo do ciclo 12x8
- Datas de embarque e desembarque
- Contagem de dias restantes
- Indicador de progresso do ciclo
- Calendário de movimentações
- Atualização automática na virada do dia
- Relógio com horário de Manaus
- Indicador de status do painel

## Tecnologias

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Contexto

O projeto faz parte do ecossistema Escala+, criado para facilitar o acesso e a visualização das escalas operacionais.
